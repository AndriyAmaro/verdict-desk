Waiting for the ledger...
  • Test the chain flips one decision in dossier ..., in a copy held in this tab. The row turns red and the banner says the chain no longer verifies.
  • Tamper and re-hash plays the cleverer attacker. The edited row looks valid again, but the next row no longer links to it: chain broken.
  • Rewrite the whole chain shows the limit. Everything verifies again, but the head hash is different. That is why the head is published outside the operator's reach.
Or edit a decision by hand

Pick a dossier, change any character of its verdict (the action, the edge, a price) and press verify. The recorded hash stays as it was, so the page can tell.

Outside this page: download the tampered copy and run python3 -m verdict_desk --ledger ledger-tampered.jsonl verify, or open the file with the file picker above. The Python verifier reports the same dossier.
